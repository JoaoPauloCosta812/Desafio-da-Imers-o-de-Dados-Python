# 🔍 Desafio da Imersão de Dados Python

Este repositório contém o **Desafio da Imersão de Dados Python**, um projeto prático realizado com o objetivo de aplicar conceitos de **análise exploratória, visualização e tratamento de dados** em um dataset real.

O desafio foi desenvolvido como parte da formação em Ciência de Dados, combinando análise estatística, gráficos e interpretação de resultados.

---

## 🧠 Sobre o Desafio

O principal objetivo deste desafio é demonstrar habilidades em Python para manipulação de dados e extração de insights significativos a partir de um conjunto de dados.

O projeto inclui:

- leitura e limpeza de dados
- análise exploratória
- visualizações gráficas
- interpretação de padrões nos dados

---

## 🎯 Objetivos do Projeto

- 📂 Carregar e explorar um dataset real  
- 🧹 Realizar tratamento de valores faltantes e inconsistências  
- 📊 Criar visualizações que revelem padrões importantes  
- 🧮 Aplicar métricas descritivas e análises estatísticas  
- 🧠 Identificar insights relevantes para tomada de decisão

## 🚀 Como Executar o Projeto Localmente

### 🔹 Pré-requisitos

Antes de começar, certifique-se de ter instalados:

- 🐍 **Python 3.7 ou superior**
- 📦 **Git**
- 📁 Ferramenta para notebooks (Jupyter ou VS Code)

---

### 🛠️ Instalação

1. Clone o repositório:

```bash
git clone https://github.com/JoaoPauloCosta812/Desafio-da-Imersao-de-Dados-Python.git
```

2. Acesse a pasta do projeto:

```bash
cd Desafio-da-Imersao-de-Dados-Python
```

3. (Opcional) Crie um ambiente virtual:

```bash
python -m venv venv
```

Ative o ambiente:

**Windows (PowerShell):**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

4. Instale as dependências:

```bash
pip install -r requirements.txt
```

---

## ▶️ Executando o Projeto

Caso o projeto esteja em **Notebook**, basta abrir:

```bash
jupyter notebook
```

ou abrir o `.ipynb` no VS Code.

Se houver script Python principal, execute:

```bash
python nome_do_script.py
```
